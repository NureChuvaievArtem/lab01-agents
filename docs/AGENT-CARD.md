## 2. Призначення
- **Предметна область:** Архітектура та бізнес-правила модульної платформи управління нерухомістю SmartLease (домени Properties, Maintenance, Finance, Utilities, Auth).
- **Зв'язок із кваліфікаційною роботою:** Тема кваліфікаційної роботи «Платформа управління орендою нерухомості SmartLease на базі модульного моноліту .NET та PostgreSQL». Агент призначений для консультацій розробників щодо інваріантів бізнес-сутностей та модульної структури системи.
- **Що робить агент:** Агент приймає запити інженерів та аналітиків щодо структури сутностей платформи, перевіряє їх наявність у детермінованій базі специфікації SmartLease та формує точну, верифіковану відповідь із зазначенням зв'язків та функціонального модуля.
- **Типові запити користувача:**
  1. *«Розкажи про сутність maintenance_request у системі SmartLease.»*
  2. *«Порівняй сутності property та lease_agreement у системі SmartLease.»*
  3. *«Які сутності входять до модуля properties_module і як пов'язаний договір lease_agreement?»*
- **Чого агент не робить (межі):** Агент не виконує операцій запису або модифікації бази даних (DDL/DML), не генерує сторонній код без посилання на специфікацію, не вигадує неіснуючих сутностей чи модулів при поверненні `NOT_FOUND`.

## 3. Архітектура
| Дія | Аргументи | Детермінована? | Змінює середовище? |
| :--- | :--- | :---: | :---: |
| `lookup_smartlease_entity` | `{"name": str}` | Так | Ні |
| `list_entities_by_module` | `{"module": str}` | Так | Ні |
| `finish` | `{"answer": str}` | — | Ні |

- **Умови зупинки:**
  * Вибір дії `finish` моделлю після накопичення всіх спостережень;
  * `MAX_STEPS = 6` (жорстке обмеження кількості кроків циклу);
  * `MAX_LLM_CALLS = 8` (бюджет викликів нейромережі).
- **Обробка відмов:**
  * `DecisionError` при невалідному JSON, невідомій дії або хибних типах аргументів $\rightarrow$ трансформація в спостереження `ERROR: ...` з наданням моделі шансу виправитися на наступному кроці;
  * Обробка `NOT_FOUND` для неіснуючих сутностей $\rightarrow$ заборона галюцинацій та завершення через `finish`;
  * Захист від зациклення за лімітами кроків та викликів LLM;
  * Ретрай при мережевих помилках API.

## 5. Запуск
- **Власний агент:** `uv run python main.py "<запит>"` (або з лімітом `--max-steps <N>`)
- **One-shot базова лінія:** `uv run python main.py "<запит>" --mode oneshot`
- **ADK-агент (CLI):** `agents-cli run "<запит>"`
- **ADK Playground:** `agents-cli playground` (веб-інтерфейс `http://localhost:8080`)
- **Змінні оточення:** `GEMINI_API_KEY` (зберігається виключно в `.env`, що доданий до `.gitignore`).

## 7. Відомі обмеження та ризики
- **Обмеження розміру середовища:** наразі охоплює 6 ключових сутностей та 5 модулів. У ЛР 02 середовище буде розширено за допомогою векторизованої бази знань Obsidian та ChromaDB.
- **Ризик вичерпання квоти (HTTP 429):** на безкоштовному тарифі діє ліміт 15 запитів/хвилину. Захист забезпечується лімітами `MAX_STEPS` та затримками між пакетними прогонами.
